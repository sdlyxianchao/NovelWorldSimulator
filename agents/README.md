# Agents（剧组职位设置）

这个文件夹里**每个 `.md` 是一个职位**，文件名用英文（`novelist.md`）。
正文默认就是该职位的**系统提示词**，frontmatter 里是它的属性。

英文名 ↔ 中文名对照：

| 文件 | English | 中文 | 作用 |
|---|---|---|---|
| `novelist.md` | Novelist | 小说作家 | 写当天这一章的原著样章 |
| `screenwriter.md` | Screenwriter | 剧作者 | 把样章改写成能拍的剧本（分场·分拍·谁做什么） |
| `writers_room.md` | Writers Room | 编剧室 | 导演·小说作家·剧作者三方会审：为该推进的故事补局部设定（只能动场景层/细节层，不碰总体设定） |
| `reviewer.md` | Retrospective | 复盘 | 每天收工复盘：剧情总结 + 存在的问题 + 后续修改意见（必要时建议改当天的戏） |
| `stylist.md` | Stylist | 造型 | 人物身上的东西：衣着·随身物·仪态 —— 给演员穿戴，并进出图提示词 |
| `sound_designer.md` | Sound Designer | 声音 | 这一场的声音层：环境音·静默·声音的转折 —— 喂给场景的环境句 |
| `polisher.md` | Language Polisher | 语言审校 | 读当天样章，点名哪几句 AI 味重、该怎么改（去 AI 库的每日深查） |
| `storyboard.md` | Storyboard Artist | 分镜师 | 把定稿剧本的分拍拆成镜头清单（镜号/景别/画面/台词/镜头运动），给导演和演员当拍摄说明书（开源漫剧「剧本→分镜」） |
| `visref.md` | Visual Reference Artist | 视觉参考图 | 分镜定稿后为出场人物/关键场景生成一致性参考图（接 image_gen），给下游生图/视频当统一参照（开源漫剧「分镜→视觉」） |
| `rehearsal.md` | Rehearsal | 排练 | 剧本定稿后把这一天**空走一遍**：哪一拍谁做不到、人不在场、写死了台词 —— 有问题就退回剧作者改 |
| `director.md` | Director | 导演 | 定框架、派活、挑事、验算、**盯戏**、收尾 |
| `actor.md` | Actor | 演员 | 在框架之内自由发挥 |
| `extra.md` | Extra | 群众演员 | 门外的人与事（外部输入） |
| `continuity.md` | Continuity | 场记 | 连戏检查：时间·物件·称呼·状态对不对得上 |
| `script_doctor.md` | Script Doctor | 剧本审读 | 上屏之前逐条读一遍：是不是人话·像不像这个人·接不接上文·是不是一个主题 —— 不通过就改写或拦下（全程记账） |
| `props.md` | Props | 道具 | 这一场该有什么物件、哪件要反复出现 |
| `art_director.md` | Art Director | 美术 | 定这一部的画风与配色，管住出图一致性 |
| `publicity.md` | Publicity | 宣发 | 写一句话卖点、看点、预告 |
| `researcher.md` | Researcher | 资料员 | 考据：这一处的名物、制度、称谓站不站得住 |
| `ingest.md` | Book Ingest | 开卷摄取 | 把作者给的资料读成能用的设定：提取人物与世界观、判类型、定风格、排进度、拟开局、按需打磨 |
| `memory.md` | Memory Summarizer | 记忆摘要 | 跨天把当天压成几句话、给后台人物补经历 —— 前情提要的来源 |
| `progress_eval.md` | Progress Evaluator | 进度评估 | 每一拍判断「这一站的判据满足了没有」—— 推进故事进度节点 |
| `compliance.md` | Compliance Review | 合规复核 | 按力度复核即将落盘的正文（独立于创作 Agent，只做判级与提示） |
| `novelservices.md` | Creation Service | 创作服务 | 外挂的写作后端（MuMuAINovel）：开卷后由它写样章（可选） |

## 软件层与项目层

- **本文件夹** = 软件层：跨所有小说生效的默认设定；
- **每个项目文件夹下的 `agents/`** = 项目层：只对那一本生效的定制；
- 运行时 = **软件层 + 项目层**（项目层只覆盖它写了的字段，其余跟软件层）。

## 想加一个自己的职位？

在「天机（程序设置）· 剧组 Agents」里点「新建」。自建职位会在**每天收工**时出工一次，产出落到那一轮运行文件夹里。

## ★ 演员：这一份管不了"演谁"（2026-10-11）

演员是唯一一个**系统层没有具体角色、项目层才有**的职位 —— 所以它的设置
分成四处，按"换什么它才变"排（越靠下越具体、越该压过上面的）：

| 层 | 在哪 | 管什么 |
|---|---|---|
| ① 系统 · 职位 | 本文件夹的 `actor.md` | 演员**这个工种**怎么干活 |
| ② 系统 · 类型库 | `actors/archetypes.yaml`（界面：天机 ·「演员类型库」） | **预写好的各种演员**怎么说话（每型含变奏轴） |
| ③ 项目 · 剧组 | `<项目>/agents/actor.md` | 这**一部戏**的演法基调 |
| ④ 项目 · **角色** | `<项目>/设定集/人物.yaml`（界面：书斋 · 演员行的 👥「角色设置」） | **张三这个人**演成什么样 |

**一句话**：①②管"怎么演"、③④管"演谁"；冲突时**以角色为准**（这句话写在提示词里，见 `actors/casting.py`）。

> ⚠⚠ **具体角色不要写进任何一份 `.md`**（包括 `actor.md`）。
> 这里的每一份都是**全剧组通读**的：把"张三高冷、李四热情"写进来，
> 等于让**每个角色都读到别人的设定**（张三会知道李四的秘密）——当场串台。
> 角色有自己**一人一份**的位置（④），见上一段那个表。

## 注意

- 软件自带的职位**不能删**（只能改）；自建职位可以删。
- 删掉项目层的那份 = 这一本回到软件默认（不会影响别的书）。
- 正文里 `<!-- … -->` 包起来的部分是**写给你看的**（说明、提醒），不会发给模型；要影响模型的话写在注释**外面**。
