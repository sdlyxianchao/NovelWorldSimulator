# 路程与交通估算

古代交通的速度上限是**硬约束**，也是最好用的戏剧工具：
「八百里加急」之所以震撼，正因为你知道那有多难。

本技能可用脚本直接算：

```bash
python skills/路程与交通估算/scripts/travel.py 1200 --mode 快马
python skills/路程与交通估算/scripts/travel.py 300 --mode 步行 --rain
python skills/路程与交通估算/scripts/travel.py --table
```

## 一、里程单位（先统一单位，否则全盘皆错）

| 单位 | 说明 |
|---|---|
| 里 | 最基本的长途单位 |
| 步 | 1 里 = 300 步（古制）；「百步穿杨」的步 |
| 舍 | 30 里 = 1 舍（「退避三舍」= 90 里） |
| 驿 / 铺 | 驿站间距单位，唐约 30 里一驿 |
| 日程 | 1 日程 ≈ 步行 1 天 ≈ 40 里（口语常说「三日程」） |

**折现代公里**：1 里 ≈ 0.5 公里（常用近似）。
严格考古：周秦汉 1 里 ≈ 416 米，唐 ≈ 460 米，明清 ≈ 576 米。
**小说里统一用「里」最安全**，一旦给出公里数就要准备被较真。

## 二、日行里程（核心表）

| 方式 | 日行（里） | 现实条件 |
|---|---|---|
| 步行（常人） | 30–50 | 背行李取低值；雨天、山路再打折 |
| 步行（急行/信使腿脚） | 60–80 | 不能持久，几天就耗干 |
| 骑驴/驮马 | 40–60 | 便宜，适合赶考的读书人 |
| 马车（载人） | 40–60 | 路况差时更慢；车轴易坏 |
| 商队（驼马驮货） | 30–40 | 队伍慢在最短的那匹 |
| 单骑快马 | 150–250 | **一匹马跑不了几天**，必须换马 |
| 驿站换马急递 | 300–600 | 「六百里加急」是制度极限 |
| 漕船（顺流） | 100–200 | 靠水力，逆流要大减 |
| 漕船（逆流拉纤） | 30–50 | 需要纤夫，成本高 |
| 海船 | 200–300 | 看风向，无风即停 |

**最重要的一条常识**：**马不是永动机。**
单骑日行 200 里或许可以撑一两天，之后马就废了。所以「快」的真相是**换马**——
这就是驿站存在的意义。写「一人一马三日千里」，马必须先累死。

## 三、驿站与补给

| 朝代 | 制度 | 间距 |
|---|---|---|
| 唐 | 馆驿 | 约 30 里一驿 |
| 宋 | 递铺 | 约 10–25 里一铺 |
| 元 | 站赤 | 约 40–60 里一站（驿马充足） |
| 明清 | 驿站 + 铺递 | 陆驿约 60–80 里，铺约 10 里 |

**能住宿的是「驿」**，且多为**官用**。平民只能住**客栈/逆旅/邸店**，或借宿寺庙、
村舍。写「夜宿驿站」的平民要留个心眼——他多半进不去。

**实际行程还要扣掉**：渡河等船、翻山改道、雨天泥泞、关卡查验、补给采买。
经验值：**理论天数 × 1.2 ~ 1.5** 才是诚实的行程。

## 四、速度的戏剧价值

| 场景 | 数字 | 效果 |
|---|---|---|
| 步行 800 里 | 约 20 天 | 「二十天前的消息」= 一切都已无法挽回 |
| 快马 800 里 | 约 4 天 | 来得及报信，但马废人乏 |
| 州县到京城 1500 里 | 急递约 3 天 | 因此地方官必须自己拿主意 |
| 漕运 2000 里 | 顺流约 15 天，逆流 40 天以上 | 粮食调运永远是慢变量 |

**写情节时的三个用法**：
1. **消息滞后**：距离越远，人物越无知——这是误会与悲剧的天然来源
2. **救援能否赶到**：先算天数，再决定谁来得及
3. **成本**：路越远，物资越贵；「千里馈粮，士有饥色」

## 五、落笔检查表

1. 单位统一了吗（全是里，或全是公里）？
2. 用了**单骑快马**却没写换马吗？
3. 扣掉 20%–50% 的**路况损耗**了吗？
4. 有没有**渡河 / 翻山 / 天气**这类真实阻碍？
5. 人物的身份能住进驿站吗？

> 拿不准两地实际距离，走考据通道查；或直接问项目设定集里有没有写过地理。
