# 古代律法常识

古代司法戏最怕两点：**罪名用错时代**，以及**程序全凭想象**（县令一拍惊堂木就定罪杀人）。

## 一、法典沿革

| 朝代 | 法典 | 里程碑 |
|---|---|---|
| 战国·魏 | **法经**（李悝） | 中国最早较系统的成文法典，分盗、贼、囚、捕、杂、具六篇 |
| 秦 | 秦律 | 出土于睡虎地秦简；严苛，连坐 |
| 汉 | 九章律（萧何） | 在法经上加户、兴、厩三篇 |
| 唐 | **唐律疏议**（653） | 中华法系的巅峰，此后各朝基本沿用其框架 |
| 宋 | 宋刑统 | 沿唐律，加「编敕」 |
| 明 | **大明律** + 大诰 | 体例改为「名例 + 六部」；朱元璋重典治吏 |
| 清 | 大清律例 | 沿明律，「例」的效力常高于律 |

**一句话**：唐以前粗疏、唐以后定型。写唐代之后的公堂戏，程序大体一致。

## 二、五刑（唐代定型）

| 刑 | 内容 | 量级 | 注意 |
|---|---|---|---|
| 笞 | 竹板打背/臀 | 10–50 下，分五等 | 最轻，多用于小过 |
| 杖 | 大杖打背/臀/腿 | 60–100 下，分五等 | 60 下已可致残 |
| 徒 | 剥夺自由服苦役 | 1–3 年，分五等 | 唐制五等：1、1.5、2、2.5、3 年 |
| 流 | 流放远地 | 2000–3000 里，分三等 | 常加「决杖」后发配 |
| 死 | 绞、斩 | **绞重于斩**（保全尸体故斩轻于绞） | 唐律绞斩二等；宋加凌迟 |

**关键细节**：
- **「绞重于斩」** 不是笔误 —— 古人重「全尸」，斩首身首异处，故绞被排在更重一档。
- 凌迟（千刀万剐）宋以后才逐步入律，**唐以前没有**，写唐代用凌迟是大错。
- 「弃市」= 在闹市处斩示众；「枭首」= 斩后悬首于木。
- 女犯多「绞」或「杖」，且唐代有「妇人犯流者留住」等变通。

## 三、常见罪名与量刑倾向

| 罪名 | 要点 |
|---|---|
| 十恶 | 谋反、谋大逆、谋叛、恶逆、不道、大不敬、不孝、不睦、不义、内乱 —— **遇赦不赦** |
| 盗 | 分「窃盗」与「强盗」；强盗持械伤人加等 |
| 杀人 | 分「谋杀」「故杀」「斗杀」「误杀」「戏杀」—— **区分故意与过失**，量刑差极大 |
| 斗殴 | 按伤情（见血、折齿、折肢）分级 |
| 奸 | 分「强奸」「和奸」；「和奸」双方皆罚 |
| 不孝 | 骂詈父母、别籍异财、居丧嫁娶皆入罪 |
| 田产 | 多属「户婚」「田宅」门 |

**「十恶」的意义**：它是「不可以钱赎、不可以赦免」的红线。写重臣落难，
若罪名不在十恶，就还有回旋（赎、赦、贬）；若入了十恶，就必死。

## 四、审理程序（唐代之后的常态）

1. **告诉**：受害人击鼓鸣冤，或由里正/保甲举发；也可由官府纠劾
2. **受理**：长官（知县/知府）受理，先「录问」（问明情由）
3. **勘验**：命案必须**检验尸伤**（宋有《洗冤集录》，是世界最早的系统法医学著作）
4. **刑讯**：允许拷讯，但**有限制**（唐律：拷囚不得过三次，总数不得过二百；
   杖罪以下不得过所犯之数）。**拷打致死，主审官要担责** —— 这是好素材。
5. **定案**：徒以上须上报复核
6. **复核**：
   - 死刑须**三复奏 / 五复奏**（唐）：向皇帝反复奏报后才可执行
   - 明代的**朝审 / 大审**，清代的**秋审 / 朝审**：每年秋后集中复核死刑
7. **执行**：死刑多在**秋后**行刑（「秋决」），因「春生秋杀」；斩在闹市

**最容易写错的程序**：
- 县令**不能**自己决定死刑（须上级复核、皇帝批准）。写「知县当场判斩」是硬伤。
- 死刑不在春夏执行（除「立决」的特殊情况）。
- 唐以前程序较简，但「人命关天」的上报原则大体一致。

## 五、赎、赦、议

- **赎**：五刑中笞杖徒流多可「以铜赎」（唐制），但十恶、殴祖父母等不许
- **赦**：新君即位、改元、祥瑞、大雩常大赦；**十恶不赦**
- **八议**：唐律对亲、故、贤、能、功、贵、勤、宾八种人，犯死罪须「议」后请旨
  —— 这就是贵族的保护伞，也是「由他议去」这类台词的由来
- **官当**：以官品抵罪（免官抵徒），唐代有之

## 六、落笔检查表

1. 这个罪名**当时叫不叫这个名字**？
2. **量刑档位**对不对（不能一言不合就流三千里）？
3. **程序**走完了吗（徒以上要复核，死罪要复奏）？
4. 有没有**该赎该赦**的余地，情节需要的话能不能用？
5. 用了**凌迟/枷号/文字狱**？先确认朝代（凌迟宋后、枷号明、文字狱清最烈）。
