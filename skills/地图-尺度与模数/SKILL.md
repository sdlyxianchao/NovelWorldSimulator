# 地图·尺度与模数（"多大"这件事的唯一答案）

## 一句话

**先有一个基准尺寸，其余全是它的比例。** 没有基准，家具会跟房间不成比例
（"柜子比门还宽"就是这么来的）。

## 四、换算到画布（**这一步最容易错**）

1. 先定 **px/m**：取一间"已知尺寸"的房间（比如明间面阔 3.6m）量它画出来多宽，
   反算 `k = 宽_px / 3.6`。
2. 家具尺寸 = 真实尺寸 × k。
3. ⚠ **不要给家具写死像素**：同一个 48px 的柜子，在 3m 和 8m 的房间里意思完全不同。
   代码里 `image_gen/furniture.py::SPECS` 给的是"参考房间（约 200×110px）下的像素"，
   换尺度时要按 `k` 重算。
4. ⚠ 画布上的**最小可读尺寸**约 8~10px：小于它的东西要么合并、要么不画
   （画出来是一片噪点，比不画更糟）。
