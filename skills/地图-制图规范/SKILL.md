# 地图·制图规范（所有地图共用，不按题材改）

## 一句话原则

**定制只影响"画什么"和"长什么样"，绝不影响"怎么读"。**

制图语法是公共约定：读者靠它看懂"这是地图"。改了它，图就不是地图了。

## 三层，各管一件事

| 层 | 要不要按题材定制 | 内容 |
|----|------------------|------|
| **制图语法** | **一律通用** | 投影、比例尺、指北针、图例、要素分级、字级、面-线-点的读法 |
| **要素清单** | **必须按题材定制** | 有没有城墙/城门/护城河、政区按什么建制、有没有驿站、路网连通性 |
| **符号语汇** | **轻度定制**（改样式不改结构） | 屋顶做法、墙线单双、底色纹理、城镇符号形状 |

## 五条硬规矩

1. **要素分级**：路必分档（主干 / 次干 / 支路），档次由**语义**决定（通往大地方的宽），
   不是"手感宽度"。参数在 `image_gen/scale.py::ROAD_SPEC`。
2. **图例只列这次真画了的**。列了没出现的，读者会去找"那条运河在哪"。
3. **综合取舍**：小于阈值的碎块舍掉（GB/T 20257.1）。阈值在
   `image_gen/scalemap.py::LOT_MIN_AREA`。
4. **不编造**：没有数据的东西不画。没有高程就不画等高线；没有水深就不画等深线；
   没有路网表就不编"国道 305"。
5. **图层顺序**：水系 → 街区/地面 → 建筑体量 → 路网 → 点符号 → 文字 → 图例。
   顺序反了就得靠"后画的盖前画的"来救，那是掩盖问题。

## 不变量（判据守着）

- 文字不压线、不压别的文字（`image_gen/minimap.py::_text` 与 `_place_label`）
- 内容不出图廓（`image_gen/scalemap.py::_clip_seg` / `_clip_rect`）
- 同一份数据两次绘制逐位一致（纯函数）
