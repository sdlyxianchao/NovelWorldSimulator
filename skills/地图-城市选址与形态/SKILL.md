# 地图·城市选址与形态（城为什么在那儿、长成什么样）

## 一句话

**城不是随便找块平地画的。** 选址有四条硬约束，形态由选址与时代共同决定。

## 一、选址四条（缺一条就活不好）

| 约束 | 看什么 | 结果 |
|------|--------|------|
| **水** | 河湾凸岸、阶地、泉、井 | 取水近、不被淹 |
| **防** | 山、河、高地、隘口 | 有天然屏障 |
| **路** | 渡口、驿道交汇、桥头 | 能做生意 |
| **资源** | 林、矿、盐、耕地 | 能养活人 |

★ 常见组合：**河湾 + 渡口**（商贸城）、**山顶/台地 + 隘口**（军镇）、
  **两河交汇**（大水城）、**驿道节点**（驿站→镇→城）。

## 二、五种形态（判据看"路网 + 边界"）

| 形态 | 路网 | 边界 | 典型 |
|------|------|------|------|
| **棋盘（里坊）** | 正交等距 | 方形城墙 | 唐长安、明清北京、现代网格 |
| **放射** | 中心放射 + 环 | 圆形/多边形城墙 | 欧洲中世纪、环形城 |
| **带状** | 一条主街 + 支巷 | 随地形 | 沿河/沿谷/沿驿道 |
| **卫城/堡** | 短放射 + 环 | 围墙 + 望楼 | 军镇、山寨 |
| **港市** | 沿岸 + 垂直码头街 | 海/湾 + 一段城墙 | 泉州、威尼斯 |

## 三、要素分布（"什么该在哪儿"）

| 要素 | 位置 | 为什么 |
|------|------|--------|
| 衙署 / 市政厅 | 城中、主街交点 | 到各处距离短 |
| 寺观 / 教堂 | 散布 + 一处主寺 | 服务半径 + 地标 |
| 市集 | 城门内外、桥头、路口 | 人流必经 |
| 仓廒 | 近水近码头、靠城墙 | 运输 + 安全 |
| 武备（营、校场） | 城边、靠城门 | 出动快、不扰民 |
| 学 / 书院 | 安静处（多靠城北/山麓） | 避开喧闹 |
| 驿站 / 马厩 | 城门外、官道旁 | 马不进主街 |

★ 判据：**市集必须在人必经的地方**。摆在城角没人去 —— 那图上就看得出来是个错。

## 四、城防（有城墙的世界必画）

| 构件 | 作用 | 画法 |
|------|------|------|
| 城墙 | 主体 | 双线（厚度），夯土/砖 |
| 城门 | 出入 | 缺口 + 门楼；主门常加**瓮城** |
| 护城河 | 拒马 | 沿墙外一圈水面 |
| 马面 / 敌台 | 侧射 | 墙上等距凸出 |
| 望楼 / 角楼 | 瞭望 | 转角与门上 |
| 关隘 | 卡口 | 两山之间一道墙 + 门 |

## 五、密度与天际线

- **密集城区**：建筑覆盖率 40%~60%（街区里"半实半空"）
- 郊野/村落：覆盖率 10%~25%
- **垂直标志**：塔、钟鼓楼、教堂尖顶、烟囱、水塔 —— 一座城通常只有 2~5 处
  ⚠ 到处是高塔 = 没有地标，读者反而认不出城心在哪

## 六、别编的东西

- 不编"城墙长度 XX 里"（没有数据）
- 不编"人口 XX 万"（推不出来）
- 不编具体城门名（除非题材档案里有）
