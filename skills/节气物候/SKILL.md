# 节气物候

「时节感」是中文小说最廉价也最有效的氛围来源，但**物候错季是最容易被读者抓到的破绽**：
八月写桃花、腊月写蝉鸣，一眼就假。

本技能可用脚本直接查：

```bash
python skills/节气物候/scripts/jieqi.py 2026-04-05      # 查某天
python skills/节气物候/scripts/jieqi.py --list          # 二十四节气全表
python skills/节气物候/scripts/jieqi.py --month 4       # 某月的节气
```

> 「候」里的说法有古人的观察错误（如「腐草为萤」「鹰化为鸠」），
> 但**写古人视角时恰恰要用这些说法** —— 人物不会说「萤火虫是鞘翅目幼虫」。
> 这是本技能最实用的地方：用当时的语言写当时的眼睛。

## 二、各季节可用的意象（按节气取，不要跨季）

**春**：柳芽、桃花、杏花、燕子、新韭、春茶（明前/雨前）、蛙声初起、地气上蒸
**夏**：蝉、荷、蒲扇、井水浸瓜、雷雨、蚊蚋、栀子、晒麦
**秋**：桂、菊、鸿雁、蟋蟀、霜、露、枫、菱藕、新米
**冬**：梅、炭火、手炉、冰、雪、腊味、更漏长

**易错搭配**（写之前心里过一遍）：

| 写错的 | 问题 |
|---|---|
| 腊月桃花 | 桃在惊蛰后 |
| 八月蝉鸣 | 蝉鸣止于立秋前后，八月中秋已衰 |
| 清明赏荷 | 荷在立夏后 |
| 冬至摘新茶 | 春茶在清明前后 |
| 端午赏菊 | 菊在寒露后 |

## 三、节日与节气的关系

- **清明**既是节气又是节日（扫墓、寒食在后世与清明合流）
- **冬至**「亚岁」，祭祖、吃饺子（北方）/ 汤圆（南方）—— 写南方冬至吃饺子要留意
- **立春**有「打春牛」、咬春（吃萝卜、春饼）
- **夏至**有「冬至饺子夏至面」之说
- 节气与**农历节日**（春节、端午、中秋、七夕、重阳）是两套体系，别混为一谈

## 四、农事要点（写乡野/生计必用）

| 节气 | 农事 |
|---|---|
| 立春—雨水 | 备耕、修农具、积肥 |
| 惊蛰—春分 | 春播开始、育秧 |
| 清明—谷雨 | 插秧（南方）、采茶、种豆 |
| 立夏—小满 | 麦子灌浆、稻田管理 |
| 芒种 | 最忙：「芒种忙，麦上场」，收麦插秧两头忙 |
| 夏至—小暑 | 双抢开始（抢收抢种） |
| 立秋—处暑 | 收早稻、晒谷 |
| 白露—秋分 | 收秋、种冬麦 |
| 寒露—霜降 | 收薯、摘棉、腌菜 |
| 立冬—小雪 | 冬藏、窖藏、腌腊 |
| 大雪—冬至 | 农闲、兴修水利 |
| 小寒—大寒 | 积肥、准备春耕 |

> 需要精确日期时跑脚本；需要"这一天什么感觉"时查三候。
