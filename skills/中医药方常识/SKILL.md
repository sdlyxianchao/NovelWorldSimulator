# 中医药方常识

写中医戏，专业性体现在**辨证用语**而不是药名堆砌。
下面只列「常用到不会错」的部分，冷僻方子宁可不写。

> ⚠ 本技能是**文学创作参考**，不是医疗建议。现实中的疾病请就医。

## 一、四诊：望闻问切

| 诊法 | 看什么 |
|---|---|
| 望 | 神色、舌苔（舌质颜色、苔之厚薄黄白）、形体 |
| 闻 | 声音（谵语、呃逆）、气味（口气、体气、排泄物） |
| 问 | 寒热、汗、头身、饮食、二便、睡眠、经带（妇人） |
| 切 | 脉象（浮沉迟数虚实……），常「寸关尺」三部 |

**八纲辨证**：阴阳、表里、寒热、虚实 —— 这八个字是中医的坐标系。
写「表寒里热」「虚不受补」这类台词，就是从这里来的。

## 二、常用方剂（唐宋已有，写唐宋以后都安全）

| 方名 | 组成（简） | 主治 | 出处 |
|---|---|---|---|
| **桂枝汤** | 桂枝、芍药、生姜、大枣、甘草 | 外感风寒**表虚**（有汗） | 伤寒论 |
| **麻黄汤** | 麻黄、桂枝、杏仁、甘草 | 外感风寒**表实**（无汗） | 伤寒论 |
| **小柴胡汤** | 柴胡、黄芩、半夏、人参、甘草、生姜、大枣 | 少阳证（往来寒热） | 伤寒论 |
| **四物汤** | 当归、川芎、白芍、熟地 | 血虚（妇人调经基础方） | 局方 |
| **四君子汤** | 人参、白术、茯苓、甘草 | 气虚 | 局方 |
| **六味地黄丸** | 熟地、山茱萸、山药、泽泻、丹皮、茯苓 | 肾阴虚 | 小儿药证直诀（宋） |
| **逍遥散** | 柴胡、当归、白芍、白术、茯苓、甘草、薄荷、煨姜 | 肝郁脾虚（妇人常用） | 局方 |
| **银翘散** | 金银花、连翘、薄荷、荆芥等 | 温病初起 | 温病条辨（**清**） |
| **安宫牛黄丸** | 牛黄、犀角、麝香等 | 热陷心包、高热神昏 | 温病条辨（**清**） |

**年代红线**：
- 「伤寒论」方（桂枝/麻黄/小柴胡）→ 汉末起可用
- 「局方」（四物/四君/逍遥）→ 宋代《太平惠民和剂局方》
- 温病派方（银翘散/安宫牛黄丸）→ **清代**才有，写唐宋用它们是穿越
- 「六味地黄丸」→ 宋代钱乙《小儿药证直诀》

**方名别称**：桂枝汤类方常称「调和营卫」；四物汤加四君子叫「八珍汤」；
加黄芪肉桂则成「十全大补汤」。

## 三、药性与配伍禁忌

**四气五味**：寒热温凉（气）+ 辛甘酸苦咸（味）。台词「此药性寒，虚人忌服」即源于此。

**十八反（配伍禁忌，必记其名）**：
- 甘草反甘遂、大戟、海藻、芫花
- 乌头反贝母、瓜蒌、半夏、白蔹、白及
- 藜芦反人参、沙参、丹参、玄参、细辛、芍药

**十九畏**：硫黄畏朴硝、水银畏砒霜、丁香畏郁金……

**妊娠禁忌**：麝香、水蛭、虻虫、巴豆、大戟等 —— 写堕胎情节要用这些。

## 四、剂型与煎服

| 剂型 | 用法 |
|---|---|
| 汤剂 | 「水煎服，日一剂，分二服」；常注「温服」「食后服」 |
| 丸 | 蜜丸、水丸；「每服二钱，温水送下」 |
| 散 | 研末冲服 |
| 膏 | 内服膏方，或外用贴敷 |
| 酒剂 | 药酒 |

**煎药讲究**：先煎（矿石类）、后下（芳香类如薄荷）、包煎（带绒毛或细小种子）、
另煎（贵重如人参）、冲服（如三七粉）。

## 五、太医与民间郎中（写人物身份用）

| 角色 | 说明 |
|---|---|
| 太医 / 御医 | 服务于皇室，唐代属太医署，明清有太医院；品级不高但风险极大（治不好要问罪） |
| 坐堂医 | 药铺里坐诊的医生，多为世医 |
| 走方郎中 | 游走乡间，常兼卖药，地位较低 |
| 药童 / 学徒 | 抓药、碾药、看铺子 |

**判病与死亡的古代判断**：无脉搏、无呼吸、身体冰冷僵硬。
「脉绝」「气绝」是常见说法，别写「心跳停止」（现代概念）。

## 六、落笔检查表

1. 这个**方子当时存在吗**？（温病派方清才有）
2. 说的**是辨证用语还是现代病名**？（「肝郁脾虚」✅ /「抑郁症」❌）
3. **药与症对得上吗**？（表实无汗用麻黄汤，表虚有汗用桂枝汤 —— 用反了要出事）
4. 涉及**堕胎/下毒**时，药性是否用在点子上（麝香、巴豆、砒石）？
