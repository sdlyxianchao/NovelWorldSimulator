# 官职品级对照

古代官场戏的张力来自「品级」。品级错了，压制关系就塌了。

## 一、品级总表（九品十八级）

每品分**正、从**两级，共十八级；四品以下再分上下阶的是个别朝代，一般不用管。

```
正一品 从一品  ← 三公、大学士、尚书（明清部分）
正二品 从二品
正三品 从三品
正四品 从四品
正五品 从五品   ← 知府（明）在此
正六品 从六品
正七品 从七品   ← 知县（明）在此
正八品 从八品
正九品 从九品   ← 未入流（典史、驿丞等）
```

**关键常识**：七品知县对四品知府，差 6 级；知县见知府要**跪**（明清）。
五品以上通常称「大人」，六品以下多称「老爷」——但各朝代习惯不同，别一概而论。

## 二、中央要职

| 官职 | 明清品级 | 职权 | 备注 |
|---|---|---|---|
| 太师 / 太傅 / 太保 | 正一品 | 荣誉虚衔（三公） | 常加给重臣，无实权 |
| 内阁大学士 | 正一品（初为五品） | 票拟、参预机务 | 明初五品，后渐尊；「首辅」为首席 |
| 六部尚书 | 正二品 | 一部之长 | 吏户礼兵刑工 |
| 六部侍郎 | 正三品 | 一部副手 | 左侍郎尊于右侍郎 |
| 都察院左都御史 | 正二品 | 总揽监察 | 御史可「风闻奏事」 |
| 大理寺卿 | 正三品 | 复审刑狱 | 与刑部、都察院合称「三法司」 |
| 翰林院学士 | 正五品 | 侍读、修史、充考官 | 品低而清贵，是入阁跳板 |
| 通政使 | 正三品 | 收受内外章奏 | |

**明代断层的要害**：1380 年朱元璋**废丞相**，六部直接对皇帝负责。
所以明中期以后没有「丞相」，说话要么称「阁老」（大学士），要么称「部堂」（尚书）。
清沿明制设内阁，但雍正后实权在**军机处**（军机大臣无定品，皆为兼差）。

## 三、地方要职

| 官职 | 品级（明清） | 辖区 |
|---|---|---|
| 总督 | 正二品（加兵部尚书衔可至从一品） | 一省或数省军政 |
| 巡抚 | 从二品 | 一省 |
| 布政使 | 从二品 | 一省民政、财赋 |
| 按察使 | 正三品 | 一省刑名、监察 |
| 知府 | 正四品（明为四品，清乾隆后正四品） | 一府 |
| 知县 | 正七品 | 一县 |
| 县丞 | 正八品 | 知县副手 |
| 主簿 | 正九品 | 文书、钱粮 |
| 典史 | 未入流 | 缉捕、狱囚 |

**唐宋对照**（写唐宋别用「总督」「巡抚」）：
- 唐：道—州—县。州长官 = **刺史**（上州从三品），县长官 = **县令**
- 宋：路—州（府）—县。州长官 = **知州**，另有**通判**牵制（可直达皇帝）
- 宋代「知某州事」的「知」就是「临时掌管」之意 —— 这也是「知县」「知府」的词源

## 四、容易搞混的几组

| A | B | 区别 |
|---|---|---|
| 尚书 | 侍郎 | 尚书是一把手，侍郎是副手（明清）；唐代则「尚书」为六部长官 |
| 御史 | 谏官 | 御史**纠弹百官**（都察院），谏官**规谏皇帝**（唐宋为谏院） |
| 节度使 | 观察使 | 唐：节度使掌军，观察使掌监察民政；安史后节度使兼领 |
| 巡抚 | 巡按 | 巡抚为常设地方大员；巡按是**临时**派出的监察御史 |
| 大学士 | 军机大臣 | 明代实权在内阁；清代实权在军机处 |

## 五、虚衔与别称

- **加衔**：本身官职之外加的头衔，为了抬身份（如「太子太保衔」「兵部尚书衔」）。
  写「加兵部尚书衔的总督」是对的，写「总督兼兵部尚书」要留意是否实授。
- **散官 / 勋官**：唐代有「散官」（定班位，如光禄大夫）+「勋官」（定功劳，如柱国）。
  写唐代人物时「官」与「散官」常并称。
- **别称**：吏部尚书 = 天官/冢宰；礼部尚书 = 大宗伯；兵部尚书 = 大司马；
  刑部尚书 = 大司寇；工部尚书 = 大司空；户部尚书 = 大司徒（多为雅称，慎用）。
- **地方雅称**：知府 = 太守（借古称）、知县 = 令尹/明府（唐宋用法）。

## 六、落笔前的三问

1. 这个官职在**这个朝代**存在吗？（「总督」明中叶才有）
2. 上下级关系对吗？（知县不能直接顶撞知府还全身而退）
3. 称呼合当时习惯吗？（唐宋不称「大人」，明以后才普遍）
