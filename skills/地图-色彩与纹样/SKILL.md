# 地图·色彩与纹样（颜色即等级）

## 一句话

**颜色不是"好看不好看"，是等级与材料的记号。** 用错色比画错形状更容易被读者察觉。

## 一、中式：颜色按等级

| 色 | 用在哪 | 谁能用 |
|----|--------|--------|
| 黄（琉璃） | 屋顶 | 皇家、敕建寺观 |
| 赤/朱 | 柱、门、墙 | 官署、庙宇、大宅 |
| 青/绿（琉璃） | 屋顶 | 王府、次要殿宇 |
| 灰（布瓦） | 屋顶 | 民居（**大量**） |
| 白（粉墙） | 墙面 | 民居、江南 |
| 黑/深褐 | 木构件（不施彩） | 民居 |

## 二、西式：颜色按材料

| 色 | 材料 |
|----|------|
| 石本色（米黄/灰） | 石灰岩、砂岩 |
| 白/米（抹灰） | 砖墙抹面 |
| 深褐/黑 | 半木构的木架 |
| 红（砖） | 清水砖墙 |
| 铅灰/铜绿 | 屋顶（铅板、铜） |

## 三、现代/未来：颜色按材料与功能

- 混凝土灰、钢的银灰、玻璃的青蓝、耐候钢的锈红
- 功能色：消防红、管道按介质上色（水蓝/气黄/电红）

## 四、纹样位置（有等级的装饰）

| 位置 | 中式 | 西式 |
|------|------|------|
| 门楣 / 门罩 | 匾额、砖雕 | 门套、雕花 |
| 檐下 | 彩画、斗栱 | 檐口线脚 |
| 柱头 | 少有 | 柱式（多立克/科林斯） |
| 栏杆 | 木栏、石栏 | 铁艺、石栏 |
| 铺地 | 方砖、卵石拼花 | 石板、马赛克 |
| 屋脊 | 脊兽（有等级） | 尖顶饰、风向标 |

## 五、三条纪律

1. **地图上不要大面积用饱和色**：会把图变成"色块拼贴"，看不出结构。
   制图上建筑用**浅灰/米/浅褐**的明度差，颜色只用来区分"是什么"。
2. **一个题材一套主色**（见题材档），不要混搭
3. **不编色号**：写"灰瓦白墙"就够了，不必给 `#RRGGBB`（画图时按调色板取）
