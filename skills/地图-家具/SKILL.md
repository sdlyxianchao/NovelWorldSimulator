# 地图·家具（室内平面上的陈设）

## 一句话

**家具在平面图上是"轴对齐的轮廓 + 少量内部线"，不画立体、不画阴影。**

★ 斜线阴影是**剖面材料**的记号，不是家具。画在家具上只会让一片房间变成一团斜纹，
  反而看不出哪件是什么。

## 摆放三条（`image_gen/roomplan.py::_pack_fixtures`）

1. **不压墙**：退让 `WALL_IN + WALL_GAP` = 4.35 + 1.8 = 6.15px。
   墙向内占 4.35px（两圈描边 inset 0 与 3.5、各 1.7）—— 只退 3px 就压进墙里。
2. **不撞门**：每面墙先算出"被门洞占掉的区间"，家具跳过它们。
   （只排上墙时不会撞；一旦四面墙都用上，不避门必然把柜子排到门口。）
3. **不叠、不丢**：家具之间留 3.0px；放不下的记 `orphans` 报出来，
   **不许静静消失**（"这口井不见了"是报过的）。

## 摆放习性三件套（`image_gen/furniture.py::FSpec`）

★ **不是所有家具都靠墙**（用户 2026-10-27 原话：「不是所有家具都是靠墙的 比如柜台
  是要有留空站人才对 别的家具你也要重新检查下怎么放」）：

| 字段 | 含义 | 取值 |
|------|------|------|
| `anchor` | 贴哪儿 | `wall` 贴墙 / `corner` 贴角 / `float` 离墙浮置 / `center` 居中 |
| `clear` | 哪几侧要留白 | `front` / `back` / `both` / `sides` / `all` / `none` |
| `clear_px` | 留多少（px） | 按"人肩宽≈0.5m、站立≈0.6m"折算，会被房间进深 clamp |

- **贴墙族**（灶/床/柜/架/椅凳/箱/筐篓）：背靠墙，净空面朝室内。
- **浮置族**（柜台/井/桌）：离墙一段（净空）摆放 ⇒ 柜台前后都能站人。
  房间太小浮置不下时**退化**成贴墙，并记 `anchor_of='wall'`（判据据此不冤它）。
- **净空怎么判**：每件家具有一个**净空区**（要留白的那几侧往外扩 `clear_px`），
  两件家具打架的判据是**矩形相交**（净空区 ∩ 对方矩形），**不是中心距** ——
  中心距会把"并排贴墙的两口柜"误判成挤（全局间隙一刀切 ⇒ 每面墙只放得下一件）。
- 净空实在不够时：**先摆上，再报"净空不足"**（`fp.tight`），不许悄悄塞进去。
