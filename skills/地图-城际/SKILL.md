# 地图·城际（城镇 / 官道 / 山川）

## 一句话

城际图只画**骨架五样**，不画街道与房屋。

1. **政区面**：Voronoi 分区，极淡填充 + **虚线**边界（实线会被读成"墙"）
2. **水系**：河/湖/海（见「地图-水系」；三类画法不同）
3. **山地符号**：名字带「山/岭/峰」的画**三角**，不画成城镇圆点 —— 山不是聚落
4. **官道**：按两端城镇等级分级，双线（驿道画法）
5. **城镇节点**：按等级分四级符号，等级越高字越大

★ 这是城际图上**唯一**能传达"哪座城重要"的手段。

## 城镇等级（`image_gen/scalemap.py::settlement_rank`）

三级判法：**档案自己的词表 → 通用并集表 → 作者给的 size → 最后才是 1**

- 中式：京师/都城（4）· 州/府（4）· 县/关/城（3）· 镇/驿/渡（2）
- 西式：castle/keep/cathedral（3~4）· town/mill（2）
- ⚠ 写死中式建制词是**真错**：`Minas Tirith`、`Dunharrow Keep` 全落 1 级 2.8px，
  有城墙的主城与村口一样大。
- 判不出仍给 1（**不抬等级**）：把村子画成州府比反过来更容易误导。

## 城际形态（题材档案的 `城际` 字段）

| 形态 | 侧重 | 用在 |
|------|------|------|
| `terrain` | 山河为主、政区压淡 | 中式、日式、废土、奇幻 |
| `administrative` | 政区为主 | 西式、民国、蒸汽、现代 |
| `nautical` | **一条政区界都不画**、航线虚线、港口画**锚** | 舟船 |

## 港口

- 港口/锚地画**锚符号**（海图约定），不画城镇圆点 —— "能停船"是海图上唯一有用的信息。
- 名字特征：港/码头/锚地/泊地/渡口/津渡。代码：`image_gen/scalemap.py::PORT_WORDS`

## 不画

- 街道、房屋（那是城市图的事）
- 等高线/高程（没有高程数据）
- 国道编号（没有路网表）
