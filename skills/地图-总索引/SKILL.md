## 使用顺序（照这个次序，不要跳）

1. **判尺度**（`image_gen/scale.py::scale_of`）：
   `室内` → `城市` → `城际` → `甲板`。尺度定错，后面全错。
2. **判题材**（`image_gen/worldstyle.py::for_layout`）：定屋顶/墙线/**路网**/**城际**四个开关。
3. **读制图规范**：`地图-制图规范`（不许改的那一层）。
4. **读对应构件档**：
   · 画一栋房子 → 建筑类型与形制 → 材料与构造 → 尺度与模数 → 室内平面 → 家具
   · 画一座城 → 城市选址与形态 → 道路与街道工程 → 街道与路网 → 城市 → 水系
5. **读题材档**：房间用词、解算次序、**五域差异**（建筑/家具/室内/道路/城市）、"还需查的"。
6. 若"还需查的"有没查过的条目 → 先查（`image_gen/artresearch.py`），查完落成技能。
