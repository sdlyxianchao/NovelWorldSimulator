# 地图·建筑类型与形制（先判"这是什么房子"）

## 一句话

**先定类型，再定形制。** 类型决定"必须有哪些房间"，形制决定"它们怎么排"。
两件事混在一起做，就会出现"客栈里没有马厩""衙署里没有大堂"。

## 一、类型表（闭集，按"必须有的东西"判）

| 类型 | 平面特征 | 必须有的元素 | 常见叫法 |
|------|----------|-------------|----------|
| **住宅** | 围合院落，卧室为主 | 门、主厅、卧房、厨、厕、院 | 宅/第/府/院/屋 |
| **店铺** | 临街窄面宽、进深深 | 铺面（柜台）、货架、后仓、住人的内院 | 铺/店/肆/栈 |
| **客栈** | 前店后宿、有院落停牲口 | 柜台、客房数间、马厩/车棚、灶房 | 客栈/旅店/驿站/邸 |
| **官署** | 中轴多进、前堂后寝 | 大门、仪门、大堂、二堂、内宅、库、狱 | 衙/署/府/厅 |
| **祠庙寺观** | 中轴对称、殿为主体 | 山门、钟鼓楼、正殿、配殿、藏经/禅房 | 寺/观/庙/祠/庵 |
| **塔** | 竖向单体、逐层收分 | 塔基、塔身、塔刹、楼梯（不可住人） | 塔/浮图/幢 |
| **堡/寨** | 围墙+望楼、道路放射 | 门楼、望楼、墙、井、仓 | 堡/寨/坞/围 |
| **驿** | 靠官道、有马厩 | 门、厅、驿舍、马厩、驿亭 | 驿/铺/亭 |
| **仓** | 大跨无隔、近水近路 | 仓廒数间、晒场、门 | 仓/廒/囷 |
| **学** | 院落+讲堂 | 门、讲堂、斋舍、藏书、院 | 学/塾/书院/庠 |
| **作坊** | 大空间+炉/碾/槽 | 工作面、料堆、成品间 | 坊/作/窑/碾 |
| **会馆/戏台** | 大跨厅堂+台 | 大厅、戏台、后台、院 | 馆/台/楼 |

⚠ 「塔」不能住人、「仓」不该有床、「戏台」不该有灶 —— 类型判错，后面全错。

## 二、单体是"三段式"

| 中式 | 西式（古典） | 现代 |
|------|-------------|------|
| 台基 | 基座（plinth） | 地面/架空层 |
| 屋身（柱+墙+门窗） | 墙身（order/柱式） | 标准层 |
| 屋顶（庑殿/歇山/悬山/硬山/攒尖） | 檐口 + 坡顶/穹顶 | 女儿墙 + 平屋面/设备层 |

## 三、大式 / 小式（中式最要紧的一条分级）

| | 大式（殿式） | 小式 |
|---|---|---|
| 面阔 | 5 ~ 11 间 | 3 ~ 5 间 |
| 通进深 | 可至 11 桁 | ≤ 7 檩，大梁以 5 架为限 |
| 斗栱 | 有 | 无 |
| 屋顶 | 庑殿、歇山；可重檐 | 悬山、硬山 |
| 瓦 | 琉璃 | 布瓦（小青瓦） |
| 用在哪 | 宫殿、官署、庙宇的主殿、府邸主厅 | 次要房屋、民居 |

**判据**：名字里有"殿/宫/大堂/正殿"⇒ 按大式；"厢房/耳房/倒座/柴房"⇒ 按小式。
⚠ 民居硬套大式（三间小屋配庑殿顶）就是"看着像宫殿的民房"，一眼假。

## 四、院落怎么排（中式住宅的骨架）

| 进数 | 排法 | 谁住 |
|------|------|------|
| 一进 | 门 → 天井 → 正房 | 小户 |
| 二进 | 门 → 前院（厅）→ 内院（正房 + 厢房） | 中等人家 |
| 三进 | 门 → 轿厅 → 大厅 → 内宅 → 后园 | 大户 |

- **中轴**上放"门—厅—堂—寝"，厢房在两侧
- **内外有别**：外人止于前厅，内宅在后
- **服务动线**（厨、柴、水）走侧门/后门，不穿主厅

## 五、判定顺序（画之前先走一遍）

1. 名字 → 类型（上表）
2. 类型 → 必须有哪几间（缺了就补，别硬画）
3. 规模 → 大式还是小式
4. 院落 → 几进、中轴怎么排
5. 才轮到"怎么画"（看 `地图-室内平面` 与 `地图-家具`）
