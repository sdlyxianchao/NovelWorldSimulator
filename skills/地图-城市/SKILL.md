# 地图·城市（街区 / 无名体量 / 要地）

## 一句话

城市图有**三层**，强度必须拉开：

| 层 | 含义 | 强度（填充） |
|----|------|-------------|
| 街区（地面） | 被街道围出的地块 | 0.06（极淡） |
| **无名建筑体量** | "这一片是建成区" | 0.32 |
| **要地（有名字的）** | 读者要找到的那几处 | 0.72 + 描边 |

★ 街区**不是物体，是地面**。画深了用户就会把它当建筑 —— 那正是"道路穿越建筑"那个报障的前提。
★ 但只有地面、没有房子，读起来像**还没动工的空地**（用户 2026-10-27 第二报："街道图里的
  其他建筑呢"）。所以中间那层"无名体量"必须画。
★ 无名体量**不算编造**：街区面本身就是推出来的（Voronoi/棋盘细分），没有名字没有归属，
  里面填体量是同一层推断的继续。**凡有名字的一律走"要地"那条路。**

代码：`image_gen/scalemap.py::block_buildings` / `_draw_massing` / `place_anchors`

## 要地（主角建筑）

- **落进某块地**，不占整块地、不以自己坐标为中心。
  实测：占其地块 **12%~19%** —— 这才是"街上的一户"。
- 尺寸按 `size` 分档（0.85 / 1.25 / 1.6 / 2.05），且**按绝对像素**换算，
  不被地块边长吞掉（否则"特大"只比"小"宽 5%）。
- 选地块时**长边与短边都要装得下**：只看长边会让 6px 深的窄地中选，中心离街不到 3px。

## 城墙

- **只读 `layout.walls`**，绝不按地点外接框"补一圈"（那是凭空造墙）。
- 有城墙的世界（中式古城、西式中世纪、日式城下町）才画。

## 取景

- 城市图用**紧凑取景**：地点**实际所占** + 12% 边距 + **水系/院墙**。
  代码：`image_gen/scale.py::tight_bounds` / `frame_px(..., also=layout_extra(layout))`
- ⚠ 只按地点取景会把比地点更靠外的海岸线推到框外（实测 y≈1079 / 画布 602）。
- 大地图与小地图**必须用同一个** `frame_px`，否则同一天两张图点位不一致。
