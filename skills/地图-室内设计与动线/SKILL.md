# 地图·室内设计与动线（房间怎么用、人怎么走）

## 一句话

**先有动线，再放家具。** 家具是动线的结果，不是先摆满再想人怎么走。

## 一、三分区

| 区 | 内容 | 位置规律 |
|----|------|----------|
| **公共**（待客/营业） | 门厅、主厅、铺面 | 临街、近门 |
| **私密**（起居/睡眠） | 卧房、内室 | 深处、靠院 |
| **服务**（后勤） | 厨、厕、仓、柴、水 | 靠外墙/后门，**不穿公共区** |

★ 判据：**服务动线能不能不经过主厅到达后门？** 不能就是排错了。
★ 中式多进院落天然满足这一条（侧门/夹道）；西式大宅靠"服务翼"（service wing）。

## 二、通道宽度（决定家具能不能"排得下"）

| 场景 | 最小 | 舒适 |
|------|------|------|
| 一人通过 | 600 | 750 ~ 900 |
| 两人错身 | 900 | 1000 ~ 1200 |
| 床侧通行 | 600 | 750 |
| 柜前（平开门） | 550 | 800 |
| 桌边（拉椅起身） | 750 | 900 |
| 厨房操作带 | 900（单排）~1200（双排） | |

⚠ 摆家具时先扣掉通道，再排 —— 反过来必然出现"柜子挡住过道"。

## 三、家具布局六条（都能被判据检查）

1. **贴墙**：柜、架、床沿墙放，中间留空（`image_gen/roomplan.py::_pack_fixtures`）
2. **成组**：桌 + 椅是一组，不要拆到房间两头
3. **对位**：桌对窗、床不对门、灶对窗（排烟）
4. **避门扇**：门后 900mm 内不放高柜（门打不开）
5. **留中心**：主厅中心留出"人站着说话"的位置，别用家具填满
6. **重物靠墙**：柜、架、缸靠承重墙，不摆房间正中

## 四、采光与通风

- **进深超过 8~10m 必须想办法**：天井（中式）、侧窗两面（西式）、天窗、高侧窗
- 厨、厕**必须有外墙**（排烟排味）——没有外墙的厨房是排不出去的
- 中式天井的作用就是"给深进深房间采光"；它不是装饰，是这个平面成立的前提

## 五、私密性梯度

门 → 前厅（外人可到）→ 内厅（熟人）→ 内室（家人）→ 后园（私密）

★ 排房间时，**越私密越往里**。把卧房摆在临街第一进，是这个年代不该有的排法。
