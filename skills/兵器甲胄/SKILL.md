# 兵器甲胄

武戏的可信度取决于**兵器与年代的匹配**，以及**是否理解兵器的物理限制**。
「一剑削断长枪」在小说里可以有，但要付代价。

## 一、兵器与年代

| 兵器 | 出现 / 盛行 | 备注 |
|---|---|---|
| 戈、矛、戟 | 先秦—汉 | 戈用于钩啄，戟兼勾刺；汉后逐渐让位于枪 |
| 剑 | 先秦—汉（**主战**）；汉后转为佩饰/武官标志 | 汉以后「剑」多是身份象征，战场用刀 |
| 环首刀 | 汉—唐 | 直刃长刀，汉军近战主力 |
| **横刀 / 唐刀** | 唐 | 直刃，装具讲究（「唐大刀」） |
| 弯刀 / 腰刀 | 宋—明清 | 出现弧度，利于劈砍；明「腰刀」为制式 |
| 长枪 | 唐以后为主战长兵 | 「枪为百兵之王」；宋代枪制极多（鸦项枪、捣马突枪） |
| 陌刀 | 唐 | 长柄双刃，专斫骑兵，唐军特色 |
| 斧钺、锤、鞭、锏 | 宋—明清 | 破甲用（钝器对甲有效） |
| 弓 | 历代 | 步弓射程约 100–150 步有效；名弓有「神臂弓」（宋，实为弩） |
| 弩 / 神臂弓 | 秦汉—宋 | 射程远、训练易；宋神臂弓号称 300 步 |
| 床弩 | 汉—宋 | 需多人操作，射城/射人 |
| 火器 | 宋（突火枪）→ 元明（火铳）→ 明（鸟铳、佛朗机、红夷大炮） | **明以前别写火枪齐射** |

**要害提醒**：
- **冶铁水平决定兵器上限**。汉代用块炼铁/炒钢，唐宋普及灌钢，明代有更成熟的高炉。
  写先秦「削铁如泥的宝刀」是幻想（青铜兵器为主）。
- **弓的拉重**决定能不能穿甲。普通弓难以穿透铁甲，这才需要弩、钝器、破甲箭。
- 「削铁如泥」「万夫不当之勇」是修辞，一旦当成物理事实，战斗就没了张力。

## 二、甲胄

| 类型 | 盛行 | 特征 |
|---|---|---|
| 皮甲 | 先秦 | 牛皮/犀皮，重量轻但防护有限 |
| 铁札甲 / 玄甲 | 汉—唐 | 甲片编缀，「玄甲军」即唐太宗精锐 |
| 明光铠 | 南北朝—唐 | 胸背有圆护，反光明亮 |
| 步人甲 | 宋 | 全装甲，重达 40 斤以上；宋军重甲步兵著名 |
| 绵甲 / 布面甲 | 明—清 | 布面钉铁片，成本低易量产 |
| 锁子甲 | 西域传入，元明较多 | 环环相扣 |

**甲胄的重量常识**：宋代步人甲约 40–60 斤，穿它的人**跑不快**、**爬不了城**，
且夏日极易中暑。写重甲武将追人三天三夜是硬伤。

**马甲**：战马也有甲（具装），南北朝—唐宋的重骑兵（如「拐子马」说法存疑）
是连人带马一起披甲 —— 但重装骑兵的**机动性极差**。

## 三、军阵与战术常识

| 概念 | 说明 |
|---|---|
| 阵 | 不是「方阵跳舞」，而是**编制与兵器搭配**（长兵在前、弓弩在后、骑兵两翼） |
| 鱼鳞 / 偃月 / 方圆 | 多为后世兵书总结的阵形名 |
| 三叠阵 / 叠阵 | 宋军对付骑兵的轮射法 |
| 骑兵冲阵 | 需要**速度**与**纪律**；马怕枪林，故需侧击或追溃 |
| 一鼓作气 | 古代靠鼓、金、旗号、号角指挥，**战场上听不清人声** |
| 鸣金收兵 | 「金」为钲/锣，退兵信号 |

**步兵克骑兵的办法**：结阵、拒马、长枪如林、弩箭齐射、利用地形（水田、山道、林）。
**骑兵克步兵的办法**：侧后包抄、追溃、断粮道。正面硬冲枪阵是下策。

## 四、攻城与守城

**攻**：云梯、冲车（撞门）、投石机（宋「砲」为人力抛石，非火炮）、
地道（穴攻）、水攻（决河灌城）、堆土山。

**守**：滚木礌石、金汁（煮沸粪便，真实且恶心，感染力强）、狼牙拍、
塞门刀车、火油、夜袭。

**必须知道的现实**：
- 攻城**极耗时间**，常以月计，靠的是断粮与内应，不是硬爬
- 「三日破城」通常意味着守方早已崩溃或内应开门
- 攻城方伤亡通常**远大于**守方

## 五、落笔检查表

1. 这个朝代**有这种兵器吗**？（火枪、凌迟式的「大炮」别提前）
2. **冶铁水平**支持吗？（青铜时代没有削铁如泥的钢刀）
3. 盔甲的**重量代价**写了吗？（重甲跑不动、怕热）
4. 战斗**听不见人声**这件事考虑了吗？（用旗鼓传令）
5. 攻城的时间成本合理吗？

> 具体兵器形制不确定时走考据通道查「朝代 + 兵器」。
