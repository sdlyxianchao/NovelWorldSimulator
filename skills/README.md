# 技能（Skills）

技能是**离线的知识包**：一份 `SKILL.md`，写清楚「什么情况用、怎么用、里面有什么料」，
必要时再附一个小脚本。

考据通道（设计稿 §8.6）的第二层提供者就是它 —— 命中技能时**零成本、零网络**，
比让 LLM 硬编答案可靠得多。

```
skills/
├── README.md              ← 本文件
├── registry.py            ← 扫描/加载/路由（程序读它）
├── __init__.py
├── 朝代制度速查/SKILL.md
├── 官职品级对照/SKILL.md
├── 古代律法常识/SKILL.md
├── 中医药方常识/SKILL.md
├── 兵器甲胄/SKILL.md
├── 节气物候/
│   ├── SKILL.md
│   └── scripts/jieqi.py
├── 路程与交通估算/
│   ├── SKILL.md
│   └── scripts/travel.py
└── 姓名称谓生成/
    ├── SKILL.md
    └── scripts/gen_names.py
```

## 一、内置的 8 个技能

| 技能 | 什么时候用 |
|---|---|
| **朝代制度速查** | 写某个朝代的官制/赋税/兵制，怕制度穿越 |
| **官职品级对照** | 查某个官几品、管什么，排上下级关系 |
| **古代律法常识** | 公堂、牢狱、冤案戏：罪名、刑罚、审案程序 |
| **中医药方常识** | 郎中、病榻、太医戏：辨证用语与常用方剂 |
| **兵器甲胄** | 打斗、军阵、攻城：兵器年代与物理限制 |
| **节气物候** | 定时节感：某日该有什么物候、什么花、什么农活 |
| **路程与交通估算** | 「三天能不能赶到」：日行里程与行程天数 |
| **姓名称谓生成** | 起名、字号、称谓（尊称/谦称/避讳） |

## 二、自己写一个技能（5 分钟）

### 1. 建目录 + SKILL.md

目录名就是技能名。**必须**有 `SKILL.md`，且**必须以 `---` 开头**（YAML frontmatter），
否则注册表会跳过它。

```markdown
---
名称: 漕运常识
版本: 1.0
分类: 历史考据
触发关键词:
  - 漕运
  - 漕船
  - 粮道
  - 转运使
用途: 写粮食调运、河工、京仓相关情节时查制度与成本。
输入: 一个环节（征粮 / 装船 / 过闸 / 交仓）
输出: 该环节的制度要点、耗时、损耗与贪腐空间
调用工具: []
脚本:
  - scripts/cost.py
---

# 漕运常识

正文写你想让 AI 知道的全部内容。
用表格、用条目都行；写得越具体，路由命中后注入的越准。
```

### 2. frontmatter 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `名称` | ✅ | 显示名，一般与目录名一致 |
| `触发关键词` | ✅ | **列表**。命中的主要依据，见下面的选择技巧 |
| `用途` | ✅ | 一句话说明"什么时候该用我" |
| `输入` / `输出` | 建议 | 帮助 AI 判断该传什么、会拿到什么 |
| `调用工具` | 可选 | 要配合的 MCP 服务或命令，如 `["虚拟时钟"]` |
| `脚本` | 可选 | 相对本技能目录的脚本路径 |
| `版本` / `分类` | 可选 | 给人看的 |

### 3. 触发关键词怎么选（最容易踩的坑）

路由是**子串匹配**，所以：

- ❌ 别用一两个字的词：写 `字`，那么「名字」「文字」「字典」全都会命中这个技能
- ✅ 用 3 字以上的**特征词**：`科举`、`漕运`、`日行`、`五刑`
- ✅ 一词多写几种说法：`赶路` / `行程` / `驿站` / `快马`
- ✅ 拿自己的词去试：`python tools/verify_mcp_skills.py` 会打印每个技能的命中情况

### 4. 附脚本（可选）

脚本放在技能目录下的 `scripts/`。约定：

- 纯 Python 标准库优先，**不要引第三方依赖**（这个项目刻意保持依赖精简）
- 支持 `--help`，出错时写 `stderr` 并返回非 0 退出码
- 在 SKILL.md 正文里写清调用示例（AI 会照抄这段）

---

## 三、验证

```bash
python tools/verify_mcp_skills.py          # 技能与 MCP 的完整验证
python tools/verify_mcp_skills.py --skills-only
```

它会检查：frontmatter 是否完整、能否被注册表加载、关键词路由是否命中、
附带脚本能否跑通。

## 四、注意

- **技能是只读的知识包**，不负责写入任何东西。想写盘的功能请做成工具/命令。
- 技能内容会作为**上下文注入**，单个 SKILL.md 建议控制在 200 行内，太长会挤占预算。
- 程序**不会**自动修改这些文件；你自己加的技能也不会被升级覆盖（新版本只会补内置的那些）。
