# 地图·水系（河 / 湖 / 海 三种画法完全不同）

## 一句话

**"一条折线"能表达的东西不止一种**。先判它是什么水，再决定怎么画。

## 三态

| 类型 | 折线的意思 | 正确画法 | 代码 |
|------|-----------|----------|------|
| **河** | 河道**中线** | 一条带（线居中加粗），两岸夹水 | `image_gen/scalemap.py::draw_water` |
| **湖** | **闭合**岸线 | 闭合轮廓 + 内部填充 | 同上 |
| **海** | **陆与海的分界** | **一侧整片填充** + **实线海岸线** | 同上 + `sea_polygon` |

★ 海用"线居中加粗"是**两处都错**：加粗是居中的 ⇒ 海被往陆地推半个带宽；
  海那一面完全没有填充 ⇒ 图上成了"沿着海岸有一条蓝色的河"。

## 怎么判（`water_kind`，按顺序）

1. 上游声明优先（JSON 的 `水系类型`：`河` / `湖` / `海`，或 `river`/`lake`/`coast`）
2. 折线**闭合**（首尾距 ≤ 短边 10%）⇒ 湖
3. 横跨 ≥55% 图宽 + **一侧几乎没有地点**（≤16%）+ **旁证** ⇒ 海
4. 其余 ⇒ **河**（含"判不准"）

★ 第 3 条的**旁证**二选一："海味"地名（海/湾/澳/滩/岛/礁/港/浦）或原始坐标超出 0~1。
  没有旁证就按河画 —— 沿河单岸的城镇也满足"一侧没地点"，全部判成海会把半张图填蓝。
★ 判不准一律按河：填错半张图比少画一片海严重得多。

## 海岸线怎么画

- 两端**画到图廓**（海一直延伸到画幅之外）。代码：`image_gen/scalemap.py::coast_line`
- **实线**。虚线会被读成政区界或等深线。
- 海域多边形 = 海岸线 + 一段图廓（水在**远离陆地重心**那一侧）。
  代码：`image_gen/scalemap.py::sea_polygon`
- **不画等深线、不画沙滩礁石**：没有水深与地质数据，画了就是编。

## 取景（最容易漏的一条）

水系必须**参与取景**。只按地点包围盒取景，比地点更靠外的海岸线会被映射到图框外，
图上**一个水元素都没有**。代码：`image_gen/scale.py::layout_extra` + `frame_px(..., also=)`。
