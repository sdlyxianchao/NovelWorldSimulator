# 地图·甲板（舟船的"室内"）

## 一句话

**船的平面是狭长一根，沿龙骨分舱。** 用矩形分带解算器只能得到"四合院形状的船"。

## 为什么单独一个尺度

| | 陆地房子 | 船 |
|---|---------|-----|
| 轮廓 | 方 | **狭长**（平行中体 + 尖首 + 方尾） |
| 分间 | 横竖分带 | **沿龙骨切舱段** |
| 见天 | 院子 | **甲板**（唯一见天面） |
| 底层 | 地下室 | **底舱**（无窗，落 B1） |

## 画法（`image_gen/scalemap.py::build_deck_shapes`）

1. 船体轮廓：平行中体 + 尖首 + 方尾
2. 沿龙骨切舱段：每段 = 船体被两条竖线裁出来的那块 ⇒ **首尾自然跟着收尖**，
   不会出现"方盒子戳出船头"
3. 舱壁留门（水密门也是门，画法同陆地）
4. 分甲板叠放（上层甲板 / 主甲板 / 底舱 B1）
5. 图例：舱室、甲板、货舱、楼梯

## 城际层

航路图（`nautical`）：**不画政区界**（海图没有国界）、航线画**虚线**、港口画**锚**。
