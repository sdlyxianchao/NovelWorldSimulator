# 姓名称谓生成

名字与称谓是**身份关系的直接编码**。古人「称字不称名」——
当面直呼其名等于骂人，这一条错了，人物关系的尊卑立刻崩塌。

本技能可用脚本直接生成：

```bash
python skills/姓名称谓生成/scripts/gen_names.py --style 唐宋 --n 5
python skills/姓名称谓生成/scripts/gen_names.py --style 明清 --surname 沈 --n 5
python skills/姓名称谓生成/scripts/gen_names.py --titles 主角 --identity 官员
python skills/姓名称谓生成/scripts/gen_names.py --styles      # 看全部风格
```

## 一、姓名的完整结构

| 部分 | 说明 | 例子 |
|---|---|---|
| 姓 | 家族 | 沈 |
| 名 | 长辈所取，**自称用名** | 砚 |
| 字 | 成年（冠礼）后取，**他人尊称用字** | 砚之 / 石溪 |
| 号 | 自取，多与志趣/居所相关，可多个 | 城南居士 |
| 小名/乳名 | 幼时称呼，长辈可用 | 阿砚、石头 |
| 排行 | 伯仲叔季；或直接「三郎」 | 沈三郎 |
| 行第 | 唐代最盛，同族大排行 | 白二十二、刘十九 |

**「名字」与「字号」的规矩**：
- **名**：长辈、君上、自己称（自称「砚」）
- **字**：平辈、下属对上司的尊称（称「砚之兄」）
- **号**：最尊，或文人相互敬称（「城南先生」）
- **直呼人「名」**：上级对下级、长辈对晚辈，或**极度轻蔑**

## 二、各时代的取名风格

| 风格 | 特征 | 示例字 |
|---|---|---|
| 先秦 | 古朴、单字多、常与排行/国名相关 | 纠、突、小白、重耳 |
| 汉魏 | 单字为主，重道德与祥瑞 | 广、信、霸、武 |
| 魏晋南北朝 | 崇玄学，「之」字流行；双名增多 | 羲之、道子、僧虔 |
| 唐 | 重排行为字，「字」常与「名」相承 | 岳飞（宋）、李商隐 |
| 宋 | 重辈分字（族谱排行字） | 赵匡胤、赵光义 |
| 明清 | 双名普遍，字讲究对仗 | 张居正（字叔大） |
| 女性 | 闺名不外传；文人雅号多 | 「某氏」「细君」 |

**唐宋之后的常见做法**：族谱给每一辈定一个「辈分字」，同辈名字中共用。
写大家族时这一条特别有用——**一读名字就知道辈分**。

## 三、称谓体系（最容易写错的部分）

### 自称（谦）

| 场合 | 自称 |
|---|---|
| 对上（臣对君） | 臣、微臣、臣妾（后妃）、奴才（清，旗人） |
| 对平辈/长辈 | 仆、愚、某、不才、小可（市井） |
| 女性 | 妾、妾身、奴家（宋元后口语）、小女子（市井） |
| 尊长对下 | 我、吾（可直接用） |
| 官员对上官 | 卑职、下官（明清）、末将（武官） |

### 对称（敬）

| 对象 | 尊称 |
|---|---|
| 泛尊称 | 君、子、足下、阁下、先生 |
| 对尊长 | 先生、夫子、长者、老丈（老者） |
| 对同辈友人 | 兄、仁兄、贤弟（称弟亦可尊） |
| 对官员 | 用**官职 + 姓**：「王大人」「李知府」「沈大人」（**明清**） |
| 对僧道 | 大师、长老、道长、仙长 |
| 对女子 | 夫人、娘子（唐以后）、小姐（宋以后渐指未婚女子）、姑娘（较晚） |

### 他称（对第三人提及自己的家人时）

**自家用谦称**：家父、家母、拙荆（妻）、贱内、犬子、小女、舍弟、舍侄
**称对方家用尊称**：令尊、令堂、尊夫人、令郎、令爱、贤弟、贵府

> 记牢这条对偶：**「令」敬对方，「家」「舍」「拙」「贱」「犬」谦自己。**
> 混用（说「令尊」指自己父亲）是最常见的硬伤。

### 称字 / 称号 / 称官 / 称地望

| 方式 | 例 |
|---|---|
| 称字 | 「砚之兄」 |
| 称号 | 「城南先生」 |
| 称官 | 「沈大人」「沈知府」（明清）；唐宋用其散官或职名 |
| 称地望 | 韩昌黎（韩愈）、柳河东（柳宗元）|
| 称谥 | 「文正公」（范仲淹） |

## 四、避讳（高级技巧，用得好很出彩）

| 类型 | 说明 |
|---|---|
| 国讳 | 皇帝及其祖上之名，全国避 |
| 家讳 | 祖先之名，本族避 |
| 避法 | **改字**（改同义字）、**缺笔**（少写一笔）、**空字**（留白/写「某」） |

**写作要点**：
- 避讳造成的改名是真实的历史动力（如「民部」改「户部」因避李世民）
- 人物对**父母之名**听到时的反应，是很细腻的性格刻画机会
- 但别滥用——只有与皇族/士族沾边的人才会被避讳卡住

## 五、落笔检查表

1. 名与字的**时代风格**对吗？（先秦别起「张浩然」）
2. 平辈**有没有直呼其名**？（除表示亲昵或轻蔑外，直呼名是失礼）
3. 尊称是「官职+姓」还是「字」？（明清多前者，唐宋多后者）
4. 提到对方家属用了**敬称**、提到自家用了**谦称**吗？
5. 「小姐」「娘子」的用法符合年代吗？（「小姐」宋以后才渐指未婚女子）

> 需要批量取名时跑脚本；已有名字想配套称谓，用 `--titles`。
