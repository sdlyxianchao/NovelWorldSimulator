## 五域差异（建筑 / 家具 / 室内 / 道路 / 城市）

★ 通用规律看构件档（`地图-建筑类型与形制` / `地图-家具` / `地图-室内设计与动线` /
  `地图-道路与街道工程` / `地图-城市选址与形态`）；这一节**只写这个题材的不同之处**。

| 域 | 通用看哪份 | 这个题材的差异 |
|----|-----------|----------------|
| **建筑** | `地图-建筑类型与形制` + `地图-材料与构造` | 石砌/巨木/魔法材料；尺度可超常规（大厅高 10m+）；种族工艺不同 |
| **家具** | `地图-家具` | 按设定（矮人厚重石木、精灵轻巧藤木、法师塔多书与器皿） |
| **室内** | `地图-室内设计与动线` | 按设定；但**动线规律不变**（服务不穿主厅、私密越深） |
| **道路** | `地图-道路与街道工程` | 按设定；但**分级规律不变**（通往大地方宽、路口要退让） |
| **城市** | `地图-城市选址与形态` | 按设定；但**选址规律不变**（水/防/路/资源） |

★ 五行里凡是"按通用规律"的，说明差异真的不存在（比如动线规律各题材通用），不是漏写。
