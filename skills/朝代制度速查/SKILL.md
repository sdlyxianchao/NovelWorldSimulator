# 朝代制度速查

写历史小说最常见的硬伤不是细节错，而是**制度穿越**——
让唐朝人考八股、让宋朝人称「大人」、让明朝人用「两税法」。
本表按「制度域 × 朝代」列出关键差异，先定位时代，再取用。

## 一、先定坐标：六个断层

把中国帝制时代切成六块，跨过断层就一定要改制度：

| 断层 | 分界事件 | 之前 | 之后 |
|---|---|---|---|
| 秦 | 前 221 | 封建（分封） | 郡县 |
| 汉魏 | 220 | 察举 / 征辟 | 九品中正 |
| 隋唐 | 589 / 618 | 九品中正（门阀） | 科举（寒门可入） |
| 唐宋 | 960 | 府兵 + 均田 | 募兵 + 不抑兼并 |
| 明 | 1368 | 宰相制 | 废丞相，六部直奏 |
| 清 | 1644 | 一条鞭法 | 摊丁入亩 |

## 二、选官制度

| 朝代 | 主流方式 | 关键点 | 常见写错 |
|---|---|---|---|
| 先秦 | 世卿世禄 | 血统决定一切 | 写成考试选拔 |
| 秦汉 | 察举（孝廉 / 贤良方正）+ 征辟 | 地方长官荐举；举主与举者成「门生故吏」 | 写成凭考试成绩 |
| 魏晋南北朝 | 九品中正 | 中正官定品；「上品无寒门，下品无势族」 | 说成公开公平 |
| 隋唐 | 科举（进士科最贵） | 隋炀帝始设进士科；唐重诗赋；须过「行卷」 | 说成宋朝式糊名 |
| 宋 | 科举大盛 + 糊名 + 誊录 | 录取量剧增；「取士不问家世」 | 说成有武举就轻视文举 |
| 明 | 科举三级 + **八股** | 童生试→乡试（举人）→会试（贡士）→殿试（进士） | 把八股写到明朝之前 |
| 清 | 沿明制 + 满汉分榜 | 前期满汉分卷；晚清废科举（1905） | 忘了满人另有仕途（笔帖式等） |

**科举称谓对照**（写考场戏必用）：
- 乡试第一 = **解元**；会试第一 = **会元**；殿试第一 = **状元**
- 连中三元 = 解元 + 会元 + 状元
- 进士分三甲：一甲三人（状元/榜眼/探花），二甲「赐进士出身」，三甲「赐同进士出身」
- 未中举的秀才，考第一叫「案首」

## 三、土地与赋税

| 朝代 | 土地 | 赋税 | 记忆要点 |
|---|---|---|---|
| 唐前期 | 均田制 | 租庸调（租=粮，庸=役折纳，调=绢布） | 「庸」可用布代役 —— 这是唐代的便利 |
| 唐后期 | 均田坏 | **两税法**（780 年杨炎） | 按资产分夏秋两次征收；中国赋税史上大转折 |
| 宋 | 不抑兼并 | 两税 + 各种杂税（「宋朝税多」） | 土地买卖自由，佃农普遍 |
| 明 | 官田民田 | **一条鞭法**（1581 张居正） | 赋役合并、折银征收 —— 白银开始主导 |
| 清 | 摊丁入亩（雍正） | 丁银并入田赋 | 「滋生人丁永不加赋」→ 人口激增 |

**白银问题**：明中后期到清，「银」才是主流结算单位。写唐宋用铜钱（文/贯，1000 文 = 1 贯）、
写明清用银两（两/钱/分），混用就露怯。

## 四、兵制

| 朝代 | 兵制 | 特征 |
|---|---|---|
| 唐前期 | 府兵制 | 兵农合一，折冲府统领，自备武器 |
| 唐后期 | 募兵 + 藩镇 | 节度使坐大 → 安史之乱 |
| 宋 | 募兵 | 强干弱枝、更戍法；「兵不识将，将不识兵」 |
| 明 | 卫所制 | 军户世袭，屯田自养；后期募兵（戚家军） |
| 清 | 八旗 + 绿营 | 旗人世代为兵；绿营为汉兵 |

## 五、地方行政层级

| 朝代 | 层级 |
|---|---|
| 秦汉 | 郡—县（二级） |
| 汉末—魏晋 | 州—郡—县（三级） |
| 唐宋 | 唐：道—州—县；宋：路—州（府）—县 |
| 元 | 省—路—府—州—县（层级最多） |
| 明清 | 省—府—县；省设巡抚/总督，府设知府，县设知县 |

**称呼要点**：知县 = 一县之长（明代正七品）。宋以后称官职一般用「官职 + 姓」
（「王知县」「李知府」），唐以前的「明府」「使君」不能套用。

## 六、与故事年代挂钩时的三条检查

1. **先查这个朝代有没有这个官**（尤其「丞相」「刺史」「节度使」「总督」）
2. **再查这个官职是不是这时候叫这个名**（如「尚书」唐代是六部长官，明代在内阁之下）
3. **最后查钱与粮的单位对不对**（文/贯还是两/石）
