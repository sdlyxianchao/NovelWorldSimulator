# 背景图原图（文生图）

这个目录存**文生图原图**。界面用的背景不是在这里直接读的，而是由
`image_gen/background.py` 的 `build_from_source()` 处理后生成两张：

| 产物 | 用途 | 规格 |
|---|---|---|
| `../title_bg.webp` | 开始界面 | 16:9 · 3840×2160 · WebP |
| `../title_bg_soft.webp` | 运行界面 | 同上，柔化 + 提亮（面板半透明，背景不能抢字） |

## 换图流程

```bash
# 1. 把新的文生图原图放进本目录（旧图先删掉或移走，否则会取体积最大的那张）
# 2. 重新构建
python make_art.py                      # 自动取本目录里体积最大的图
python make_art.py --from 某张图.png    # 或指定某一张
python make_art.py --res 2560x1440      # 换输出分辨率
# 3. 验证
python tools/verify_background.py
```

> **注意：本目录必须有一张原图。** 目录空了的话，`get_bg()` 会在
> `title_bg.webp` 缺失时退回**程序化绘制**（`generate_title_background()`）——
> 那张图是几何拼的，很不好看。所以换图时**用新的换掉旧的，不要先删后加**。

## 当前版本

**v1：无锡鼋头渚 · 春季烟雨（写实优化版）** —— 文件 `鼋头渚_春季_v1_archive.webp`。

生成方式：文生图（`ImageGen` 工具），尺寸 1536×1024，quality=high，
再裁成 16:9、放大到 3840×2160、轻锐化（UnsharpMask radius 2.2 / 55% / 阈值 3）。

使用的提示词（可直接复用）：

> 实景风光摄影作品，江苏无锡太湖鼋头渚春季清晨。湖岸成片盛开的粉白樱花（染井吉野）
> 枝条自画面上方与两侧探入，繁密而不杂乱；中景是平静辽阔的太湖水面，蒙着薄薄晨雾，
> 水面上几艘白帆木船缓缓行驶，远处是太湖仙岛与鹿顶山的青黛色山影，隐约可见长春桥的
> 拱形石桥轮廓；近岸垂柳新芽嫩绿。江南烟雨季节柔和的漫射光，蒙蒙细雨在空气中形成淡淡
> 水汽，但整体画面明亮通透、色彩清丽不发灰。主色调为天青灰蓝、湖水青碧、樱花粉白、
> 柳芽嫩绿。广角横幅构图，前景樱花、中景湖水帆影、远景山影三层景深，电影级自然光，
> 高动态范围，细腻质感，高清摄影，无人物，无文字，无水印，无签名，无边框。

**为什么原图要单独存档**：文生图是一次性的（同样的提示词也出不了同一张图），
把原图留下来，以后换分辨率、调柔化强度都还能重来；提示词一并记在这里，
是为了下次想微调时不用从零猜。

### 本地版：`image_gen/watercolor.py`（当前正在用的）

等不了出图服务，所以写了**纯 Pillow 的本地淡彩水彩**当兜底 ——
不联网、零成本、约 3 秒一张 4K：

```bash
python make_art.py --watercolor     # 重建 title_bg.webp / title_bg_soft.webp
python tools/verify_background.py   # 11 项断言
```

它是**写意**的，靠「大块晕染 + 湿边 + 纸纹」逼近水彩观感；
构图按界面需求定：**右侧**鼋头渚半岛（崖岸 + 樱花 + 垂柳）、
**左下**长春桥、**左中**湖面帆影与远山、**正中刻意留空**（标题在那儿）。

实测对比 v1：

| | 平均亮度 | 平均饱和 |
|---|---|---|
| v1 写实照片 | 206 | 0.208 |
| v2 本地淡彩水彩 | 209 | **0.110** |

—— 色确实退了一半，符合"淡彩"；但**它不是照片、也不是真水彩扫描件**，
细节撑不起来。AI 版能出的时候建议换掉。

## 备注

- 提示词里明确写了「**无文字、无水印、无签名、无边框**」——界面背景上不能出现这些。
- 生成尺寸受服务上限限制（最长边 1536），所以 4K 是靠放大得到的；
  `make_master()` 里的轻锐化就是为了补这个，**不要调重**，重了会出现镶边。
- 柔化参数（模糊半径、纸色混合、亮度、饱和）在 `image_gen/background.py`
  的 `make_soft()` 里；`tools/verify_background.py` 会用「高通 std 下降」
  和「文字对比度」两条断言守住它 —— 改动后跑一遍就知道有没有过头。
